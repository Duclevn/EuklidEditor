## MDLite 0.7.1 — Preview keeps your place while you edit

A lightweight native editor (Qt 6 + Scintilla) with built-in Preview and Terminal.

A maintenance release after 0.7.0's native Preview: fixes found in a code review of 0.7.0, the unused browser code for PDF, images and CSV removed, and internal restructuring.

### Changes since 0.7.0

**Preview**
- Editing a Markdown or CSV/TSV file with Preview open no longer jumps the Preview back to the top after each change. It keeps your place (for CSV, also the horizontal position). Opening another document still starts at the top.
- Pictures in a Markdown document are decoded once and reused while you edit, instead of being read and decoded again after every change. A picture that changes on disk is read again.
- Switching from a Markdown tab with a diagram or formula to a plain Markdown tab no longer shows the previous document for a moment.
- The browser no longer contains any code for PDF, images or CSV/TSV. Since 0.7.0 these were always drawn by MDLite itself; the browser now refuses such documents outright.

**Inside**
- The main window's code is split into one file per area, and the hot-exit backup rules (which tabs are backed up, when, and what happens after a failed write) moved into their own unit-tested parts. No change in behavior is intended.

### Requirements
- Windows 10 (1809 or later) or Windows 11, x64.
- Documents that still need the browser (Markdown with diagrams or math, HTML, SVG, OpenAPI, YAML) and the Terminal use the Microsoft Edge **WebView2 Runtime**, which comes preinstalled on Windows 11.

### Install
- **Microsoft Store:** https://apps.microsoft.com/detail/9NGXBT327D13. It is signed by Microsoft, so there is no SmartScreen warning. The 0.7.1 update reaches the Store after certification.
- **Installer:** run `MDLite-0.7.1-windows-x64-setup.exe`. It updates an existing 0.5.x, 0.6.x or 0.7.0 install in place. The app is not code-signed yet, so Windows SmartScreen may ask you to confirm: choose "More info", then "Run anyway".
- **Portable:** unzip `MDLite-0.7.1-windows-x64.zip` anywhere and run `MDLite.exe`. The portable copy does not register "Open with". If you unzip over an older portable copy, delete the old `preview` and `terminal` folders first.

Settings, `keybindings.json` and hot-exit backups are stored in your user profile (AppData). They are kept when you uninstall or update.

### Validation and known limits
- **Automated tests:** built with Qt 6.8.3 / MSVC 2022 on Windows 11. 81 automated tests, run one at a time: all 81 passed. In the first full run one window-layout test (`WorkspaceNativeLayoutTests`) hung and was stopped; it then passed 8 times on its own and in a second full run. The cause is not known yet. New checks cover the kept Preview place, the picture reuse, the tab switch, the browser refusing PDF/image documents, and the hot-exit backup rules without a window.
- **Install tests:** the deployment smoke test passed for the package and for a silent installer update from 0.7.0 (the update left exactly the package's 101 files and registered the file types); the silent uninstall removed every file and the file-type registration.
- **Memory:** editor-only memory is 16.4–16.5 MiB private working set (whole process tree, 1600×1000 window, Explorer open, no file, 3 runs). The package size is unchanged (zip 22.1 MiB).
- **Known limit:** in the native Markdown Preview, a very large document refreshes slowly after each edit (about 1.9 s for a 700 KB document); ordinary documents are not affected.
- **Needs a manual check:** pointer and keyboard use with a real mouse, and a live screen reader session.
- **Not yet validated:** Windows 10, clean-machine installs, Linux/macOS (no Preview/Terminal host there yet).
