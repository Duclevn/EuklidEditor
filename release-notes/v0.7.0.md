## MDLite 0.7.0 — a much lighter Preview: PDF, images, CSV and Markdown without a browser

A lightweight native editor (Qt 6 + Scintilla) with built-in Preview and Terminal.

This release changes how Preview draws most documents. PDF, images, CSV/TSV and ordinary Markdown are now drawn by MDLite itself instead of by the embedded Microsoft Edge (WebView2) browser, which was where most of the memory went.

### Changes since 0.6.6

**Memory (whole process tree, 1600×1000 window, private working set)**

| Preview of | 0.6.6 | 0.7.0 |
|---|---|---|
| PDF (3.9 MB) | 199 MiB | **42 MiB** |
| PDF, maximized on a 4K screen | 296 MiB | **74 MiB** |
| CSV (3,000 rows) | 111 MiB | **21 MiB** |
| Markdown | 101 MiB | **22 MiB** |
| Image | about 91 MiB | **20 MiB** |
| Markdown + Terminal | 159 MiB | 118 MiB |
| Terminal | 127 MiB | 113 MiB |

The editor alone is unchanged. The package is bigger: the zip grows from 16.5 MiB to 22.1 MiB (PDF engine, image decoders, code colors).

**Preview**
- **PDF** is drawn by Qt PDF in MDLite. Scroll, fit to width, `Ctrl`+wheel zoom, page indicator, select text and copy, find (`Ctrl+F`, `F3`), internal links and web links (web links still ask first). Not included yet: outline and thumbnails, rotate, print, save. Password-protected, damaged and over-20,000-page PDFs show a "No preview" page with the reason.
- **Images** (PNG, JPEG, still GIF, BMP, WebP, TIFF) with Fit, Actual size, zoom, Reset, and a Light/Dark/Grid background. Animated, oversized and damaged images show a "No preview" page. SVG still uses the browser.
- **CSV and TSV** in a native table with the same summary line, row-limit notice, sticky header and full values on hover; `Ctrl+C` copies the selected cells.
- **Markdown** without Mermaid, PlantUML or math is drawn natively, with code blocks colored by KDE's KSyntaxHighlighting, headings that links like `#section` jump to, tables, task lists and quotes. A document with a diagram or a formula still uses the browser as before. Not carried over to the native view: note boxes (`> [!NOTE]`), copy buttons on code blocks, the table-of-contents button, front matter as a table (shown as a YAML block), and HTML beyond what Qt's rich text supports.
- Pictures in Markdown load only from the document's own folder (no link or junction is followed) or as small `data:` pictures; remote pictures stay blocked.
- Preview and Terminal now run the embedded browser without its GPU process (10–15 MiB less each).

**Removed**
- The JSON and XML Preview. These files show a short "Nothing to preview" page; the editor still highlights them. OpenAPI documents in JSON and YAML files are still previewed.

### Requirements
- Windows 10 (1809 or later) or Windows 11, x64.
- Documents that still need the browser (Markdown with diagrams or math, HTML, SVG, OpenAPI, YAML) and the Terminal use the Microsoft Edge **WebView2 Runtime**, which comes preinstalled on Windows 11.

### Install
- **Microsoft Store:** https://apps.microsoft.com/detail/9NGXBT327D13. It is signed by Microsoft, so there is no SmartScreen warning. The 0.7.0 update reaches the Store after certification.
- **Installer:** run `MDLite-0.7.0-windows-x64-setup.exe`. It updates an existing 0.5.x or 0.6.x install in place. The app is not code-signed yet, so Windows SmartScreen may ask you to confirm: choose "More info", then "Run anyway".
- **Portable:** unzip `MDLite-0.7.0-windows-x64.zip` anywhere and run `MDLite.exe`. The portable copy does not register "Open with". If you unzip over an older portable copy, delete the old `preview` and `terminal` folders first.

Settings, `keybindings.json` and hot-exit backups are stored in your user profile (AppData). They are kept when you uninstall or update.

### Validation and known limits
- **Automated tests:** built with Qt 6.8.3 / MSVC 2022 on Windows 11. 80 automated tests, run one at a time: 78 passed and 2 were skipped because their test window could not take the foreground (`WorkspaceStartPageTests`, `WorkspaceOpenEditorsTests`). New checks cover the native PDF, image, CSV and Markdown views (selection, search, links, zoom, damaged and hostile files, a junction next to a Markdown picture), the Markdown routing rules, and that no browser process starts for these formats.
- **Install tests:** the deployment smoke test passed for the package and for a silent installer update from 0.6.6 (the update left exactly the package's 101 files and registered the file types); the silent uninstall removed every file and the file-type registration.
- **Memory:** editor-only memory is 18.3–18.4 MiB private working set (whole process tree, 1600×1000 window, Explorer open, one file, 3 runs).
- **Security note:** PDF, image and Markdown pictures are now decoded inside MDLite.exe (Qt PDF/PDFium and Qt's image decoders) instead of in the browser's sandbox. Files are checked first (16 MiB, dimensions, animation) and decoded with limits, but a malformed file is handled by MDLite itself.
- **Needs a manual check:** pointer and keyboard use with a real mouse, and a live screen reader session.
- **Not yet validated:** Windows 10, clean-machine installs, Linux/macOS (no Preview/Terminal host there yet).

Third-party notices are included in the package (`licenses/`, `terminal/THIRD_PARTY_NOTICES.md`). New in this version: Qt PDF with PDFium, Qt Image Formats (libwebp, libtiff) and KSyntaxHighlighting (its syntax definition files carry their own licenses: mostly MIT and LGPL, some GPL).
