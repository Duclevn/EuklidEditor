## MDLite 0.6.5 — Find and Replace in Files, start page, syntax highlighting for 49 languages

A lightweight native editor (Qt 6 + Scintilla) with built-in Preview and Terminal.

### Changes since 0.6.4

**New**
- **Find in Files** (`Ctrl+Shift+F`, or the magnifier on the left bar) opens a Search page in the sidebar.
  - Results are grouped by file, with line numbers, and a click opens the match.
  - Options: match case, whole word and regular expressions.
  - "Files to include" and "Files to exclude" take globs such as `src/, *.md`; they are remembered.
  - Search also reads the unsaved text of open tabs.
- **Replace in Files** (`Ctrl+Shift+H`) replaces every listed match after asking first.
  - Open files are changed in their tab as one undo step and stay unsaved.
  - Closed files are saved directly, keeping their encoding, BOM and line endings. This cannot be undone.
  - Files changed since the search are skipped and named.
- **Start page.** With no document open, the editor shows Open File, Open Folder, your recent files and folders, and the main keys. Just start typing for a new file.
- **Open Recent** (`Ctrl+R`) keeps the last 10 files and 10 folders. The Command Palette lists the commands you used recently first.
- **Help › Keyboard Shortcuts** (`Ctrl+K Ctrl+S`) and **Help › Documentation**.
- **Syntax highlighting for 49 languages**, including TypeScript, CSS, shell, PowerShell, SQL, CMake, Go, Rust and more.
- **Editor layout:** View › Editor Layout › Single (`Alt+Shift+1`) or Two Columns (`Alt+Shift+2`), and a split button next to the Preview button.
- **Many open tabs:** when the tab strip scrolls, a list button opens **Show All Editors** (`Ctrl+K Ctrl+P`), which marks unsaved files. **Reopen Closed Editor** (`Ctrl+K Ctrl+Shift+T`) reopens the last closed file at its cursor.
- **Keyboard:** `Ctrl+1` / `Ctrl+2` / `Ctrl+3` focus the editor, Preview and Terminal (opening them if needed), and `F6` / `Shift+F6` move between panes. Opening the Terminal puts the cursor in it. Every menu item now has its own access key.

**Look and feel**
- One amber accent at a time. Toggled buttons draw their icon in the text color.
- The title-bar button for View only reads **Read** with a book icon. The eye now means only Preview.
- Tab names stay readable (about 20 characters before the strip scrolls). Long names elide with "…" and show the full name on hover.
- Better contrast in all three themes, a visible keyboard focus ring on tabs and left-bar buttons, and the current Find match is outlined.
- Rounded scrollbar thumbs in the editor and Explorer, matching the Preview.
- In the Default theme the left bar is always the window color, and the Explorer uses the same paper tone as the Preview.
- Warning messages use a themed icon instead of the yellow Windows triangle.

**Preview**
- Code and plain-text files show a short "Nothing to preview" page instead of a copy of the editor. No browser is started for them, which saves about 70 MiB.
- CSV: one table with a sticky header, column widths that fit the values, full headers, and a "300 rows × 5 columns" summary. The status bar names CSV and TSV.
- Themed scrollbars and borderless controls. Text stops at a comfortable reading width, while tables and code may be wider.
- Markdown table headers follow the column alignment.

**Narrow windows**
- Preview toolbars stay on one row and move extra buttons into a "More actions" menu.
- The Explorer takes less room below 720 DIP and steps aside below 600 DIP.
- When the sidebar and the Preview do not both fit, the one you opened last stays. The other one's button stays lit but muted, and pressing it brings that panel back.

**Accessibility and Windows settings**
- With a Windows screen reader running, the Terminal turns on xterm's screen reader mode.
- With "Show animations in Windows" off, the Terminal cursor stops blinking and the loading bar stands still.

**Fixes**
- Opening or closing many tabs is much faster: 200 tabs went from 56 s to 2.3 s.
- Stopping the Terminal shell now says so, and Start is available again.
- A slow regular expression in Find in Files can be stopped at once.
- Building the source in a new build folder no longer stops while copying the console host.

### Requirements
- Windows 10 (1809 or later) or Windows 11, x64.
- Preview and Terminal use the Microsoft Edge **WebView2 Runtime**, which comes preinstalled on Windows 11.

### Install
- **Microsoft Store:** https://apps.microsoft.com/detail/9NGXBT327D13. It is signed by Microsoft, so there is no SmartScreen warning. The 0.6.5 update reaches the Store after certification.
- **Installer:** run `MDLite-0.6.5-windows-x64-setup.exe`. It updates an existing 0.5.x or 0.6.x install in place. The app is not code-signed yet, so Windows SmartScreen may ask you to confirm: choose "More info", then "Run anyway".
- **Portable:** unzip `MDLite-0.6.5-windows-x64.zip` anywhere and run `MDLite.exe`. The portable copy does not register "Open with". If you unzip over an older portable copy, delete the old `preview` and `terminal` folders first.

Settings, `keybindings.json` and hot-exit backups are stored in your user profile (AppData). They are kept when you uninstall or update.

### Validation and known limits
- **Automated tests:** built with Qt 6.8.3 / MSVC 2022 on Windows 11. All 68 automated tests passed, run one at a time. New checks cover:
  - Find and Replace in Files (globs, encodings, open and closed files, stale files, undo);
  - the start page, Open Recent and Keyboard Shortcuts;
  - syntax highlighting, readable labels, contrast and focus;
  - the sidebar and Preview in narrow windows;
  - keyboard reach (pane focus, F6, access keys) and the open editors list;
  - the Windows screen reader and animation settings.
- **Design review:** an independent UI/UX review (Impeccable) scored 25/40 before this release's fixes and 30/40 after.
- **Install tests:**
  - Deployment smoke tests passed for the package and for an installer update from 0.6.4. The update left exactly the package's 89 files and registered the file types.
  - The silent uninstall removed every file and the file-type registration.
  - The Store package's local test layout registered and started.
- **Memory:** editor-only memory is 15.8 MiB private working set (whole process tree, 1600×1000 window, 3 runs). The new features load only when used.
- **Needs a manual check:** pointer and keyboard use with a real mouse, and a live screen reader session.
- **Known issues:**
  - Programs started from the Microsoft Store version of PowerShell run outside MDLite's process group.
  - Windows contrast themes are followed by the Preview but not by the rest of the window, and the Windows text size setting does not change the window's own text.
  - "Open with" in the Microsoft Store version has not yet been checked on a Store install.
- **Not yet validated:** Windows 10, clean-machine installs, Linux/macOS (no Preview/Terminal host there yet).

Third-party notices are included in the package (`licenses/`, `terminal/THIRD_PARTY_NOTICES.md`).
