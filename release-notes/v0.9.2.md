## Euklid Editor 0.9.2 — Terminal colors of its own, a document icon and a new Settings window

A lightweight native editor (Qt 6 + Scintilla) with built-in Preview and Terminal.

### Changes since 0.9.1

**Terminal colors**
- The Terminal now stands apart from the editor in every theme: an aubergine background in Dark, a soft purple in Default, and a dark One Half Dark Terminal in Light, where text on the old white background was hard to read.
- **Terminal: Select Color Scheme** (Run menu, also in Settings > Terminal) gives the Terminal its own colors, independent of the color theme: Campbell, Campbell Powershell, One Half Dark and Light, Solarized Dark and Light, Tango Dark and Light. **Follow Color Theme** goes back to the theme's colors.
- Terminal text keeps a minimum contrast against its background, in every scheme.

**A document icon for your files**
- With the installer or the Store version, files associated with Euklid Editor show a document icon in File Explorer instead of the app logo.

**A new Settings window**
- Settings is organized into pages (General, Editor, Terminal, Shell) with a list on the left.

**Fixes and polish**
- A folder passed to the app (command line, Open with, a second launch) opens as the workspace instead of being refused.
- In the Command Palette, typing `:` or `@` now switches from Commands to Go to Line or Go to Symbol.
- After Restart on a running Terminal tab, Clear no longer keeps the old prompt beside the new one.
- User Guide: the replacement syntax reads `$1` (or `\1`) again, and the download size is current.

### Known issues
- Opening a file whose single line is about 10 MB takes about 6 seconds.
- After **Reset Zoom** the line spacing can be 2 px tighter than at a fresh start, until you restart.
- HTML Preview does not load local `<link rel="stylesheet">` files, CSS `url()` pictures or inline `<svg>`.
- With a screen reader, menu shortcuts are announced as access keys (a limit of Qt's accessibility bridge).
- The User Guide inside the app still lists the old Settings groups; the copy in this repository is current.
- Not yet validated: Windows 10, clean-machine installs, a live screen-reader session and real-mouse use. Windows is the only supported platform; Linux builds are unsupported nightlies.

### Requirements
- Windows 10 (1809 or later) or Windows 11, x64.
- Documents that still need the browser (Markdown with diagrams or math, HTML, SVG, OpenAPI, YAML) and the Terminal use the Microsoft Edge **WebView2 Runtime**, which comes preinstalled on Windows 11.

### Install
- **Microsoft Store:** https://apps.microsoft.com/detail/9NGXBT327D13. It is signed by Microsoft, so there is no SmartScreen warning. The 0.9.2 update reaches the Store after certification.
- **Installer:** run `EuklidEditor-0.9.2-windows-x64-setup.exe`. It updates an existing install in place (settings, keybindings, profiles, hot-exit tabs and the browser profile are kept). The app is not code-signed yet, so Windows SmartScreen may ask you to confirm: choose "More info", then "Run anyway".
- **Portable:** unzip `EuklidEditor-0.9.2-windows-x64.zip` anywhere and run `EuklidEditor.exe`. The portable copy does not register "Open with" or the document icon. If you unzip over an older portable copy, delete the old `preview` and `terminal` folders first.

Settings, `keybindings.json`, `profiles.json` and hot-exit backups are stored in your user profile (AppData). They are kept when you uninstall or update.

### Validation and known limits
- **Automated tests:** built with Qt 6.8.3 / MSVC 2022 on Windows 11. 132 automated tests, run one at a time: all 132 passed, none skipped. The `EuklidEditor.exe` these tests ran on is the one published here (SHA-256 in the table above).
- **Install tests:** three silent installs of the published installer: an update of the released 0.9.1 installer into a temporary folder, the same update with the default folder, and a fresh install. Each left exactly the package's 102 files, 18 file types pointing at the document icon and 82 "Open with" values, and each silent uninstall removed every file and registration.
- **Memory:** editor-only private working set was 17.4-17.5 MiB at a 1600×1000 px window (Explorer open, no file); the published 0.9.1 measured the same way the same day gave 17.5-17.6 MiB. The zip is 22.6 MiB (0.9.1: 22.5).
- **Not repeated for this update:** the scripted acceptance set and the independent QC run. The document icon was checked in the registry and in the package, not by looking at File Explorer.
