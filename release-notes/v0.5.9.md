## MDLite 0.5.9 — colored file icons, clearer toolbar, MDLite.exe

A lightweight native editor (Qt 6 + Scintilla) with built-in Preview and Terminal. This release makes files easier to tell apart, makes the Preview and Terminal buttons say what they do, and gives the program its product name in Windows.

### Changes since 0.5.8
- **The program is now `MDLite.exe`.** Task Manager and Windows' file properties show "MDLite" instead of "Workspace.exe". The installer replaces the old `Workspace.exe` when you update, and the Start menu/desktop shortcuts point to the new file. Your settings stay where they were and are kept.
- **Colored file and folder icons.** The Explorer, the tabs and Quick Open use the [Symbols](https://github.com/miguelsolorio/vscode-symbols) icon theme (MIT), so Python, Java, C++, JSON, Markdown and other files each have their own colored icon. Common folders (`src`, `tests`, `docs`, `.git`, `node_modules`, …) have their own icons too.
- **Clearer Preview and Terminal buttons.** Preview is shown as an eye and Terminal as a `>_` prompt, instead of generic "panel" icons.
- **No stray strip above the Preview button.** The small rectangle above the Preview button at the end of the tab strip is gone.
- **Less memory after a Terminal session ends.** If the Terminal panel is hidden and its shell has exited, the Terminal view is released after 30 s. About 80 MiB is freed at 1600×1000 when Preview isn't open. Showing the Terminal again starts a fresh shell. A running shell is never closed.
- License: GPL-3.0-or-later, with the third-party licence set included in the package (now including `licenses/symbols-LICENSE.txt`).

### Requirements
- Windows 10/11 x64. Preview and Terminal use the Microsoft Edge **WebView2 Runtime** (preinstalled on Windows 11).

### Install
- **Installer:** run `MDLite-0.5.9-windows-x64-setup.exe`. It updates an existing 0.5.x install in place. The app is not code-signed yet, so Windows SmartScreen may ask you to confirm ("More info" → "Run anyway").
- **Portable:** unzip `MDLite-0.5.9-windows-x64.zip` anywhere and run `MDLite.exe`. If you unzip over an older portable copy, delete its `Workspace.exe`.

Settings are stored in your user profile (AppData) and are kept when you uninstall or update.

### Validation and known limits
- Built with Qt 6.8.3 / MSVC 2022 on Windows 11. All 39 automated tests passed, including new checks for the executable name and version info, the file/folder icon mapping, and releasing the Terminal view.
- Deployment smoke tests passed for the package and for an installer install. An update from the 0.5.8 installer was tested: `Workspace.exe` was removed and the shortcut pointed to `MDLite.exe`. The silent uninstall removed the files, the Start menu shortcut and the uninstall entry.
- Icons add about 180 KB to the executable and about 0.1 MiB of memory. Editor-only memory is about 15 MiB at 1600×1000 px with no file open (more on large or high-DPI windows).
- The changes in this release were not independently reviewed.
- Not yet validated: Windows 10, clean-machine installs, Linux/macOS (no Preview/Terminal host there yet), live screen-reader sessions.
