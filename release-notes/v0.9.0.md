## Euklid Editor 0.9.0 — the new name, the Tools menu and a built-in User Guide

A lightweight native editor (Qt 6 + Scintilla) with built-in Preview and Terminal.

**MDLite is now Euklid Editor.** The name, the executable (`EuklidEditor.exe`) and the icon changed; everything you had — settings, keybindings, profiles, open tabs and unsaved edits — is kept, and an installed 0.8.x is updated in place (see *Install*).

### Changes since 0.8.0

**The name**
- The product is **Euklid Editor** everywhere: window title, menus, dialogs, the installer, the uninstall entry, shortcuts and the **Open with** registrations. The old `MDLite.exe` and the `MDLite.*` file-type entries are removed during the update.
- A new logo: three coloured panes (red, cyan, yellow) with the terminal prompt as its glyph.

**Tools menu**
- **Compare Files** (`Tools › Compare Files`): two files side by side, the differing lines tinted, added and removed lines marked in the gutter, and `F7` / `Shift+F7` to jump between the differences. Unsaved edits are compared as you see them, a file can be compared with itself after a change, trailing whitespace can be ignored, and encoding, BOM, line endings and a missing final line break are reported separately.
- **Base64 Encode / Decode** and **URL Encode / Decode**: they work on every selection, or on the whole document when nothing is selected, as a single undo step. Invalid input leaves the document untouched and the status bar says why.

**Built-in User Guide**
- **Help › Documentation** (`F1`) opens the full guide in its own window, offline, with a table of contents, search and the complete shortcut list. The Command Palette keeps `Ctrl+Shift+P`.

**Smaller changes**
- The Explorer's left edge no longer touches the window frame.
- The Terminal shows its tab strip only from the second tab, and tab labels are centred, so a single terminal takes no extra height.

### Known issues
- After **Replace All, Undo or a case transform over many thousands of places** (for example 10,000 matches in a 1 MiB file, or 9,000 selections), the window can stay busy for several seconds **while a screen reader or another UI Automation client is running**; the edit itself is done in milliseconds. This was measured for 0.8.0 with such a client attached and was not re-measured for this release. Everyday edits are not affected.
- With a screen reader, menu shortcuts are announced as access keys (a limit of Qt's accessibility bridge).
- Not yet validated: Windows 10, clean-machine installs, a live screen-reader session and real-mouse use. Linux and macOS have no Preview or Terminal yet.

### Requirements
- Windows 10 (1809 or later) or Windows 11, x64.
- Documents that still need the browser (Markdown with diagrams or math, HTML, SVG, OpenAPI, YAML) and the Terminal use the Microsoft Edge **WebView2 Runtime**, which comes preinstalled on Windows 11.

### Install
- **Microsoft Store:** https://apps.microsoft.com/detail/9NGXBT327D13. It is signed by Microsoft, so there is no SmartScreen warning. The 0.9.0 update reaches the Store after certification, and the Store listing is being renamed to Euklid Editor.
- **Installer:** run `EuklidEditor-0.9.0-windows-x64-setup.exe`. It updates an existing 0.5.x, 0.6.x, 0.7.x or 0.8.x install in place: your settings, keybindings, profiles, hot-exit tabs and the browser profile are kept, the shortcuts and the uninstall entry are renamed, and the old `MDLite.exe` and `MDLite.*` registrations are removed. An updated install keeps the folder it was installed in (so an old install stays under `...\Programs\MDLite`, now holding `EuklidEditor.exe`); a new install goes to `...\Programs\Euklid Editor`. The app is not code-signed yet, so Windows SmartScreen may ask you to confirm: choose "More info", then "Run anyway".
- **Portable:** unzip `EuklidEditor-0.9.0-windows-x64.zip` anywhere and run `EuklidEditor.exe`. The portable copy does not register "Open with". If you unzip over an older portable copy, delete the old `preview` and `terminal` folders and the old `MDLite.exe` first.

Settings, `keybindings.json`, `profiles.json` and hot-exit backups are stored in your user profile (AppData). They are kept when you uninstall or update.

### Validation and known limits
- **Automated tests:** built with Qt 6.8.3 / MSVC 2022 on Windows 11. 118 automated tests, run one at a time: all 118 passed, none skipped. The `EuklidEditor.exe` these tests ran on is the one published here (SHA-256 in the table above); only documentation and screenshots changed afterwards.
- **Scripted checks:** the 34-case scripted acceptance set was run against this build: 34 passed. The full 200+ case acceptance run was **not** done for this version, which changes the name, the logo and adds new features at once.
- **Install tests:** three silent installs of the published package: an update of the released 0.8.0 installer in a temporary folder, an update with the default folder (which keeps the old folder name), and a fresh install. Each left exactly the package's 101 files, no `MDLite.exe`, 18 file types under the new name and no `MDLite.*` keys, and each silent uninstall removed every file and registration. The machine's own 0.6.3 install, its registry entries and its shortcuts were unchanged afterwards.
- **Memory:** editor-only private working set was 17.3-17.4 MiB at a 1600×1000 px window (Explorer open, no file); the 0.8.0 build measured the same way the same day gave 17.2-17.3 MiB. A larger window costs more (Windows keeps a picture of every pixel). The zip is 22.4 MiB, the same as 0.8.0.
- **Needs a manual check:** pointer and keyboard use with a real mouse, bulk edits without a screen reader attached, and a live screen reader session.
