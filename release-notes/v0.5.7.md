## MDLite 0.5.7 — leaner Preview text path and file-open fixes

A lightweight native editor (Qt 6 + Scintilla) with built-in Preview and Terminal. This is a small follow-up to 0.5.6 with memory and correctness fixes.

### Changes since 0.5.6
- **Preview text sent in one pass:** text Preview (up to 5 MiB) is decoded and escaped in 64 KiB chunks straight into the message sent to the renderer, instead of first building a full UTF-16 copy of the document. The editor buffer is read without growing Scintilla's buffer. The message content is unchanged, including invalid UTF-8. Measured with a 4.36 MiB Markdown file in Preview: Workspace.exe peak 79.1–79.4 → 77.8–77.9 MiB, settled 32 → 31 MiB (the peak is mostly set while WebView2 copies the message, which this change cannot avoid).
- **Closed Preview frees its document:** when a closed Preview releases its browser after 30 s, it also drops its copy of the document text. Reopening Preview builds a fresh one from the editor.
- **Open-file size limit enforced once:** the file size is read once and clamped to the 64 MiB limit, so a file that grows while it is opened can no longer make the editor allocate above the limit.
- **Screen readers:** the text-inserted accessibility event on file load and reload is sent again while assistive technology is active.

### Requirements
- Windows 10/11 x64. Preview and Terminal use the Microsoft Edge **WebView2 Runtime** (preinstalled on Windows 11).

### Install
- **Installer:** run `MDLite-0.5.7-windows-x64-setup.exe`. The app is not code-signed yet, so Windows SmartScreen may ask you to confirm ("More info" → "Run anyway").
- **Portable:** unzip `MDLite-0.5.7-windows-x64.zip` anywhere and run `Workspace.exe`.

Settings are stored in your user profile (AppData) and are kept when you uninstall or update.

### Validation and known limits
- Built with Qt 6.8.3 / MSVC 2022 on Windows 11. 36/36 automated tests passed. Deployment smoke tests passed for the package and for an installer install, and the silent uninstall removed the files and the Start menu shortcut.
- The changes in this release were not independently reviewed.
- Not yet validated: Windows 10, clean-machine installs, Linux/macOS (no Preview/Terminal host there yet), live screen-reader sessions.
- With Preview open on a large image, memory still peaks briefly inside WebView2 while it receives the image (≈215 MiB for a 14 MiB image).
- Editor-only memory is about 15 MiB at 1600×1000 px with no file open (more on large or high-DPI windows); the 30 MB target holds only for small windows.

Details: `docs/footprint-0.5.6.md` in the source archive. Third-party notices are included in the package (`licenses/`, `terminal/THIRD_PARTY_NOTICES.md`).
