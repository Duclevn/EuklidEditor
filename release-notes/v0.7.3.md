## MDLite 0.7.3 — Format Document, a "+" button for new tabs, and faster bulk edits

A lightweight native editor (Qt 6 + Scintilla) with built-in Preview and Terminal.

New editing features, and the fixes from a full run of the 143-case acceptance catalogue against 0.7.2.

### Changes since 0.7.2

**New**
- **Format Document** for JSON (also JSON with comments) and XML/SVG: `Shift+Alt+F`, the Edit menu, the Command Palette, or right-click in the editor. It re-indents with your indentation setting and changes nothing else: key order, number and string text, comments, CDATA, attributes and whitespace-sensitive XML content stay exactly as written. A file with a syntax error is left untouched and the status bar tells you where the error is. The whole format is one Undo step, and a document that is already formatted is not modified at all. Documents up to 16 MiB; large ones are formatted in the background (a 5 MiB minified JSON takes about 30 ms).
- A **"+" button** at the end of each editor tab strip creates a new file (same as `Ctrl+N`). With many tabs it stays pinned at the right end of the strip; in a split editor each group has its own.

**Editing**
- Replace All, Undo of a Replace All, Transform to Uppercase/Lowercase, Indent and similar commands over thousands of selections or matches are now fast. Replace All of 10,000 matches in a 1 MiB document took about 21 s and now takes about 0.01 s; Transform to Uppercase over 9,000 selections took 75 s and now takes about 0.2 s.
- A file whose first line is very long (for example a 2 MiB minified file) opens about twice as fast.

**Explorer**
- A folder that is a symbolic link or junction is shown dimmed with a tooltip and is not expanded, so the Explorer can never lead out of the workspace through a link. Files reached through links still open.

**Preview**
- OpenAPI documents in JSON are shown in Swagger UI again (since 0.7.0 only YAML was).
- Markdown that only contains prices such as "$5 and $7" is drawn by MDLite itself and no longer starts the browser; `$x$` and `$$…$$` formulas still use it. The math rule is now identical in both renderers (a closing `$` must follow a non-space and must not be followed by a digit).
- A binary file with Preview open shows the "Nothing to preview" page without starting the browser.
- The header band of a CSV/TSV table in the light theme no longer shows a dark block to the right of the last column.

**Accessibility and wording**
- The main window's accessible name now follows its title (it stayed on the profile name), so screen readers and automation read "file.txt - MDLite".
- The start page and the other texts no longer list JSON among the previewed formats (JSON has no Preview since 0.7.0).
- `MDLite.exe --version` and `--help` are titled "MDLite" instead of "Workspace".

### Requirements
- Windows 10 (1809 or later) or Windows 11, x64.
- Documents that still need the browser (Markdown with diagrams or math, HTML, SVG, OpenAPI, YAML) and the Terminal use the Microsoft Edge **WebView2 Runtime**, which comes preinstalled on Windows 11.

### Install
- **Microsoft Store:** https://apps.microsoft.com/detail/9NGXBT327D13. It is signed by Microsoft, so there is no SmartScreen warning. The 0.7.3 update reaches the Store after certification.
- **Installer:** run `MDLite-0.7.3-windows-x64-setup.exe`. It updates an existing 0.5.x, 0.6.x or 0.7.x install in place. The app is not code-signed yet, so Windows SmartScreen may ask you to confirm: choose "More info", then "Run anyway".
- **Portable:** unzip `MDLite-0.7.3-windows-x64.zip` anywhere and run `MDLite.exe`. The portable copy does not register "Open with". If you unzip over an older portable copy, delete the old `preview` and `terminal` folders first.

Settings, `keybindings.json` and hot-exit backups are stored in your user profile (AppData). They are kept when you uninstall or update.

### Validation and known limits
- **Automated tests:** built with Qt 6.8.3 / MSVC 2022 on Windows 11. 85 automated tests, run one at a time: all 85 passed, none skipped. New tests cover Format Document (the formatter, its properties on 5 MiB inputs, and the editor command), the "+" button, bulk-edit speed with limits, OpenAPI JSON detection, the Preview routing of binaries and prices, the Explorer's linked folders and the window's accessible name.
- **Black-box checks:** the whole 143-case acceptance catalogue plus 20 new cases was run against 0.7.2 (163 cases: 125 passed, 17 failed, 3 blocked, 6 manual, 12 adapted). The fixes above answer those failures, each with an automated test; the catalogue was **not** run again against 0.7.3. Not fixed: the Windows screen-reader bridge (Qt) shows menu shortcuts as access keys, and accessibility calls time out while a dialog opened from a menu is open. Three accessibility reports (pane cycling with F6, Preview toggle, Find counter) could not be reproduced and are covered by new checks.
- **Install tests:** the deployment smoke test passed for the package and for the installed copy after a silent update from 0.7.2 (the update left exactly the package's 101 files and registered the file types); the silent uninstall removed every file and the file-type registration.
- **Memory:** editor-only private working set was 16.5-16.6 MiB at a 1600×1000 px window (0.7.2: 16.1-16.2 MiB measured the same day). The package size is unchanged (zip 22.1 MiB, `MDLite.exe` +55 KB).
- **Known limits:** Format Document handles JSON and XML only, formats the whole document (not a selection), and does not reflow XML attributes. In the native Markdown Preview, a very large document refreshes slowly after each edit (about 1.9 s for 700 KB); native tables have no border lines and a block quote has no left bar.
- **Needs a manual check:** pointer and keyboard use with a real mouse, and a live screen reader session.
- **Not yet validated:** Windows 10, clean-machine installs, Linux/macOS (no Preview/Terminal host there yet).

Third-party notices are included in the package (`licenses/`, `terminal/THIRD_PARTY_NOTICES.md`).
