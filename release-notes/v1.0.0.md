## Euklid Editor 1.0.0 — a new editor engine, Replace in Files and a Terminal that works like a workplace

A lightweight native editor (Qt 6 + Scintilla) with built-in Preview and Terminal.

### Changes since 0.9.2

**A new editor engine**
- The text editor moved to **Scintilla 5** and the application to **Qt 6.12 LTS**. Keys, encodings, safe saving and syntax highlighting work as before, with more languages colored (TeX and LaTeX, PHP inside HTML) and screen-reader support rebuilt for the new editor.
- Typing Vietnamese with Unikey (including VNI) works in the editor and the Find box; AltGr characters can be typed in the Preview and the Terminal.
- The Preview, Terminal and Markdown libraries were updated to current versions.

**Search and replace**
- **Replace in Files** shows what each replacement will do before you confirm, and you can take single results or whole files out of it. Case can be preserved, and the whole replacement is one undo step in each open file.
- Find in Files is faster, and Markdown redraws pause while you type in long documents.
- Find now uses one grammar everywhere (the editor's Find bar and Find in Files).

**Markdown Preview**
- The native Markdown view (no browser needed) now looks like the full Preview: the same type sizes, spacing, code blocks and tables, in every theme.
- **Preview zoom:** Ctrl+wheel and the zoom keys zoom the Preview in Edit mode, with a level of its own.
- After **Export as PDF**, you can open the file or show it in its folder.

**The Terminal as a workplace**
- A bottom Terminal starts at a comfortable height, shows its tab strip from the second tab on, can be renamed, and folds its header into a menu when narrow. A slimmer scrollbar matches the window's.
- Right-click a Terminal tab for Rename, Duplicate, Close, Close Others and Close All.
- **Open Terminal Output in Editor** sends a tab's output to a new document.
- The **`euklid` command** works in every Terminal tab: `euklid file.txt:12:3` opens a file at a line and column in the running window.
- **Add Note to Terminal** types `path:41-47 — your note` for a coding agent that has no editor link.
- The Claude Code link review window can be answered safely while you type and announces changes to screen readers.

**Fixes and polish**
- A new logo, plain at every size.
- Files: saving keeps file attributes (Hidden, System); a chosen encoding survives a reload from disk; Compare with Version Before Reload works for a file that was deleted and written again; the raw-bytes save warning reads differently for text and binary files; the caret stays on a character start after a line tool.
- A file name with no dot (such as `Makefile`) gets a language only when you list it.
- Settings and Reset Settings wording say what they really change.
- Security hardening.
- The installer removes the old editor library files (QScintilla) when it updates an install from 0.9.x.

### Known limits
- A Markdown file with a very large number of headings can make the native Preview slow.
- A Markdown file over 20,000 lines shows its first 2,000 lines in the Preview, with a notice.
- HTML Preview does not load local `<link rel="stylesheet">` files, CSS `url()` pictures or inline `<svg>`.
- With a screen reader, menu shortcuts are announced as access keys (a limit of Qt's accessibility bridge).
- Not yet validated: Windows 10, clean-machine installs, a live screen-reader session and real-mouse use. Windows is the only supported platform; Linux and macOS builds are unsupported nightlies.

### Requirements
- Windows 10 (1809 or later) or Windows 11, x64.
- Documents that still need the browser (Markdown with diagrams or math, HTML, SVG, OpenAPI, YAML) and the Terminal use the Microsoft Edge **WebView2 Runtime**, which comes preinstalled on Windows 11.

### Install
- **Microsoft Store:** https://apps.microsoft.com/detail/9NGXBT327D13. It is signed by Microsoft, so there is no SmartScreen warning. The 1.0.0 update reaches the Store after certification.
- **Installer:** run `EuklidEditor-1.0.0-windows-x64-setup.exe`. It updates an existing install in place (settings, keybindings, profiles, hot-exit tabs and the browser profile are kept). The app is not code-signed yet, so Windows SmartScreen may ask you to confirm: choose "More info", then "Run anyway".
- **Portable:** unzip `EuklidEditor-1.0.0-windows-x64.zip` anywhere and run `EuklidEditor.exe`. The portable copy does not register "Open with" or the document icon. If you unzip over an older portable copy, delete the old `preview` and `terminal` folders first, and the old `qscintilla2_qt6.dll` and `Qt6PrintSupport.dll`, which 1.0 no longer uses.

Settings, `keybindings.json`, `profiles.json` and hot-exit backups are stored in your user profile (AppData). They are kept when you uninstall or update.

### Validation and known limits
- **Automated tests:** built with Qt 6.12.0 / MSVC 2022 on Windows 11. 141 automated tests, run one at a time: all 141 passed, none skipped. The `EuklidEditor.exe` these tests ran on is the one published here (SHA-256 in the table above).
- **Install tests:** three silent installs of the published installer: an update of the released 0.9.2 installer into a temporary folder, the same update with the default folder, and a fresh install. Each left exactly the package's 102 files (no file of 0.9.2 remained that the package does not contain), 18 file types pointing at the document icon and 82 "Open with" values, and each silent uninstall removed every file and registration.
- **Scripted acceptance set:** 34 of 34 automated checks passed on the installed build (launch, file round trips, hot exit, editing, Find, Preview routing, Terminal, View only, themes, layout, accessibility names). An independent QC run on release candidates of this version found no regressions; it was not repeated on this exact build.
- **Memory:** editor-only private working set was 16.9-17.1 MiB at a 1600×1000 px window on a 200 % display (Explorer open, no file). The zip is 23.8 MiB; without the Preview, Terminal and ConPTY files it is 19.9 MiB.

Third-party notices are included in the package (`licenses/`, `terminal/THIRD_PARTY_NOTICES.md`).
