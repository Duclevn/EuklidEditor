## MDLite 0.5.10 — hot exit, a Terminal that survives, safer deletes

A lightweight native editor (Qt 6 + Scintilla) with built-in Preview and Terminal. This release comes from a three-reviewer audit of 0.5.9. It keeps your unsaved work across restarts, keeps the Terminal's shell running when a browser helper process crashes, and makes deleting files safer.

### Changes since 0.5.9
- **Hot exit.** Closing MDLite no longer asks you to save. Unsaved edits (up to 16 MiB per tab) and your open tabs come back the next time you start it, and you are told if a file changed on disk in the meantime. You can turn this off in Settings ("Keep unsaved changes and open tabs on exit").
- **The Terminal keeps running.** Before, if a WebView2 helper process (GPU or utility) restarted, the Terminal's shell and everything running in it were closed. Now the shell keeps running, and if the Terminal view itself is lost it is rebuilt and reconnects to the same shell.
- **Closing asks if a command is still running** in the Terminal.
- **Deleting in the Explorer moves items to the Recycle Bin.** Permanent deletion is offered only if that fails, with a second confirmation. Deleting a folder never follows a link or junction out of the workspace, even if the folder changes while it is being deleted.
- **The caret starts at the top of a file you open** (it used to start at the end).
- **Saving works after a sync tool touched the file.** A file whose date changed but whose content did not is no longer refused. Large UTF-8 files are saved with fewer copies in memory.
- **Terminal links** (OSC 8) open only web links, after the same confirmation that Preview uses. Line wrapping now matches what Windows does.
- **Preview:** two tabs with the same OpenAPI file name no longer share state; reopening Preview doesn't render twice; local links are checked again right before they open; remote images are never allowed by the page policy; PDF and image previews say exactly why a file can't be shown.
- **New app icon** (four-colour pinwheel), and the Explorer background follows theme switches right away.
- **Old browser data is cleaned up.** Folders left by MDLite 0.5.5 and earlier (`PreviewWebView2`, `TerminalWebView2` in your AppData) are removed in the background unless an older MDLite is running.
- **Installer:** updating now replaces the `preview`, `terminal` and `licenses` folders, so no old files are left behind. Windows 10 version 1809 or later is required.
- **Licences:** the package now includes Qt's third-party notices and the Scintilla licence. The QScintilla 2.14.0 source archive is attached to this release.

### Requirements
- Windows 10 (1809 or later) or Windows 11, x64. Preview and Terminal use the Microsoft Edge **WebView2 Runtime** (preinstalled on Windows 11).

### Install
- **Installer:** run `MDLite-0.5.10-windows-x64-setup.exe`. It updates an existing 0.5.x install in place. The app is not code-signed yet, so Windows SmartScreen may ask you to confirm ("More info" → "Run anyway").
- **Portable:** unzip `MDLite-0.5.10-windows-x64.zip` anywhere and run `MDLite.exe`. If you unzip over an older portable copy, delete the old `preview` folder first.

Settings and hot-exit backups are stored in your user profile (AppData) and are kept when you uninstall or update.

### Validation and known limits
- Built with Qt 6.8.3 / MSVC 2022 on Windows 11. All 42 automated tests passed in two full runs, including new tests for hot exit, Terminal recovery after GPU/utility/renderer/browser process exits, the running-command prompt, Recycle Bin deletes and link-safe folder removal.
- On the installed build, the WebView2 GPU process was killed with Preview and Terminal open. It restarted, and the shell and both views kept running. Editor-only memory is about 17 MiB at 1600×1000 px.
- Deployment smoke tests passed for the package and for an installer update from 0.5.9. No old files were left behind, and the silent uninstall removed the files and the uninstall entry.
- Known issues: in the Terminal, Ctrl+C does not stop a console program such as `ping` under PowerShell (it works under Command Prompt). Programs started from the Microsoft Store version of PowerShell run outside MDLite's process group.
- Not yet validated: Windows 10, clean-machine installs, Linux/macOS (no Preview/Terminal host there yet), live screen-reader sessions.

Third-party notices are included in the package (`licenses/`, `terminal/THIRD_PARTY_NOTICES.md`).
