## MDLite 0.6.4 — Split editor, safer saves, Terminal copy/paste

A lightweight native editor (Qt 6 + Scintilla) with built-in Preview and Terminal.

### Changes since 0.6.3

**New**
- **Split editor.** View › Split Editor (Ctrl+\\) shows the current file side by side in a second group. Both sides edit the same document.
  - Ctrl+Alt+Right/Left moves a tab to the other group.
  - Ctrl+K, then Ctrl+Right/Left moves the focus to the other group.
  - Closing the last tab of a group removes the split.
  - Find, the Command Palette, Preview and the status bar follow the group you are working in.
  - Both groups come back after a restart.
- **Copy and paste in the Terminal**, as in Windows Terminal:
  - Ctrl+C copies the selection; without a selection it still stops the running command.
  - Ctrl+V pastes. Ctrl+Shift+C and Ctrl+Shift+V always copy and paste.
  - Right-click copies the selection, or pastes when nothing is selected.
- **Toggle Terminal is now Ctrl+Shift+T.** Ctrl+\` still works.
- **Preview follows the language you pick.** In an untitled tab, or after choosing a language in the status bar, the Preview renders that language without saving the file first: Markdown, HTML, JSON/OpenAPI, YAML, XML or SVG.
- **Reset Settings…** in Settings and in the Command Palette. It keeps your open files and unsaved work. It can also reset keyboard shortcuts if you tick that option.
- **Help › About** shows the edition, component versions, links to the Microsoft Store, the project and issue reporting, and the copyright and license.

**Layout**
- The Explorer and Terminal buttons are on the left activity bar.
- The Preview button sits at the top right of the tab strip.
- The title bar keeps only the menus, the command center and View only.
- Maximize now works through Windows, so Snap Layouts appear when you hover over the maximize button. A maximized window also reopens maximized.
- Corners use one consistent radius, and the line number of the current line is highlighted.

**Safer saving**
- MDLite no longer overwrites a file you do not have permission to write. It says so and suggests Save As.
- A program that is reading the file while you save no longer makes the save fail. If another program locks the file, the message says so.
- Edits restored after a restart do not overwrite the file if it was changed while MDLite was closed.
- Unsaved tabs are never dropped past the 200-tab session limit.

**Fixes and smaller changes**
- A very large JSON file in Preview uses far less memory. For a 2.6 MB test file the total memory went from about 531 MiB to 135 MiB.
- Markdown Preview has one clear 1 MiB limit with a clear message. Other text formats keep 5 MiB.
- The CSV summary counts every row.
- Two tabs with the same file name show the folder that tells them apart.
- Status-bar messages no longer overlap the folder name.
- Edit › Selection has Transform to Uppercase/Lowercase.
- The Command Palette has "Go: Back" and "Go: Forward".
- Tooltips show the keys from your `keybindings.json`.
- A maximized Terminal survives window resizes.
- Better support for screen readers and other UI Automation tools: the Explorer's expand/collapse, toggle buttons, and menu commands that open dialogs.
- Faster Find bar, Go to File and hot-exit saves.
- On a light taskbar, the Store version's icon no longer sits on a blue square once Windows has picked up the new package.

### Requirements
- Windows 10 (1809 or later) or Windows 11, x64.
- Preview and Terminal use the Microsoft Edge **WebView2 Runtime**, which comes preinstalled on Windows 11.

### Install
- **Microsoft Store:** https://apps.microsoft.com/detail/9NGXBT327D13. It is signed by Microsoft, so there is no SmartScreen warning. The 0.6.4 update reaches the Store after certification.
- **Installer:** run `MDLite-0.6.4-windows-x64-setup.exe`. It updates an existing 0.5.x or 0.6.x install in place. The app is not code-signed yet, so Windows SmartScreen may ask you to confirm: choose "More info", then "Run anyway".
- **Portable:** unzip `MDLite-0.6.4-windows-x64.zip` anywhere and run `MDLite.exe`. The portable copy does not register "Open with". If you unzip over an older portable copy, delete the old `preview` and `terminal` folders first.

Settings, `keybindings.json` and hot-exit backups are stored in your user profile (AppData). They are kept when you uninstall or update.

### Validation and known limits
- **Automated tests:** built with Qt 6.8.3 / MSVC 2022 on Windows 11. All 57 automated tests passed, run one at a time. New checks cover:
  - the split editor;
  - Terminal copy/paste, and a maximized Terminal surviving resizes;
  - safe saving (permissions, readers, locked files, edits restored after a restart);
  - native maximize and restore;
  - Reset Settings;
  - the Preview language mode and the About box;
  - the taskbar icon variants;
  - the accessibility fixes.
- **Acceptance suite:** an independent black-box QC run of 143 cases found the issues fixed in this release.
- **Install tests:**
  - Deployment smoke tests passed for the package and for an installer update from 0.6.3. The update left exactly the package's 89 files and registered the file types.
  - The silent uninstall removed every file and the file-type registration.
  - The Store package's local test layout registered and started.
- **Memory:** editor-only memory is 14.6–14.9 MiB private working set (whole process tree, 1600×1000 window, 3 runs).
  - Splitting the editor did not change it.
  - With a Markdown file in Preview the whole tree is about 97 MiB, most of it the WebView2 runtime.
  - A document with Mermaid/PlantUML diagrams peaks at about 185 MiB and drops back to about 100 MiB a minute after the last diagram render.
- **Needs a manual check:**
  - Snap Layouts (hover over maximize) and Terminal copy/paste with a real mouse and keyboard.
  - The taskbar icon on a light taskbar, once the Store update is installed.
- **Known issues:**
  - Programs started from the Microsoft Store version of PowerShell run outside MDLite's process group.
  - Screen readers announce menu shortcuts as access keys (a Qt limitation).
  - "Open with" in the Microsoft Store version has not yet been checked on a Store install.
- **Not yet validated:** Windows 10, clean-machine installs, Linux/macOS (no Preview/Terminal host there yet), live screen-reader sessions.

Third-party notices are included in the package (`licenses/`, `terminal/THIRD_PARTY_NOTICES.md`).
