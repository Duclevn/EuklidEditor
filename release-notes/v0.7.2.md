## MDLite 0.7.2 — Markdown tables with line breaks, and View only without the browser

A lightweight native editor (Qt 6 + Scintilla) with built-in Preview and Terminal.

A fix release for two problems in the native Preview that arrived with 0.7.0.

### Changes since 0.7.1

**Preview**
- A Markdown table with a line break inside a cell (`<br>`) is drawn correctly again. In 0.7.0 and 0.7.1 such a cell was cut at the break, the rest of that table went missing, and the tables after it came out with empty cells. The break now shows as a line break in the cell, as it did before 0.7.0.

**View only**
- Switching to View only on a plain Markdown file no longer starts the browser. The file was already drawn by MDLite itself, but the browser (about 80 MiB of extra memory) was created first and then sat unused. Files with a diagram or a formula still use the browser, as before.

### Requirements
- Windows 10 (1809 or later) or Windows 11, x64.
- Documents that still need the browser (Markdown with diagrams or math, HTML, SVG, OpenAPI, YAML) and the Terminal use the Microsoft Edge **WebView2 Runtime**, which comes preinstalled on Windows 11.

### Install
- **Microsoft Store:** https://apps.microsoft.com/detail/9NGXBT327D13. It is signed by Microsoft, so there is no SmartScreen warning. The 0.7.2 update reaches the Store after certification.
- **Installer:** run `MDLite-0.7.2-windows-x64-setup.exe`. It updates an existing 0.5.x, 0.6.x or 0.7.x install in place. The app is not code-signed yet, so Windows SmartScreen may ask you to confirm: choose "More info", then "Run anyway".
- **Portable:** unzip `MDLite-0.7.2-windows-x64.zip` anywhere and run `MDLite.exe`. The portable copy does not register "Open with". If you unzip over an older portable copy, delete the old `preview` and `terminal` folders first.

Settings, `keybindings.json` and hot-exit backups are stored in your user profile (AppData). They are kept when you uninstall or update.

### Validation and known limits
- **Automated tests:** built with Qt 6.8.3 / MSVC 2022 on Windows 11. 81 automated tests, run one at a time: all 81 passed, none skipped. New checks cover tables with line breaks (the Markdown view and the line-break rewrite) and View only on plain Markdown (fails without the fix).
- **Black-box checks:** 34 scripted acceptance cases run against the installed build (launch, file encodings and saving, hot exit, editing, Find and Replace, palette, native and browser Preview routing, Terminal, View only, themes, window sizes, split editor): 33 passed. The one failure is an accessibility item, seen in some starts only: the window's accessible name can stay `Profile-<name>` while its title is right. The rest of the 143-case acceptance catalogue had not been run when this version was released.
- **Install tests:** the deployment smoke test passed for the package, for the installed copy after a silent update from 0.7.1 (the update left exactly the package's 101 files and registered the file types) and for the Microsoft Store package layout; the silent uninstall removed every file and the file-type registration.
- **Memory:** editor-only private working set was 16.4 MiB at a 1600×1000 px window in the acceptance run. The footprint script (`tests/Measure-Footprint.ps1`) reported 34.7–35.7 MiB for this version today, and 34.3–34.8 MiB for the published 0.7.1 measured the same way on the same machine today (it reported 16.4 MiB for 0.7.1 yesterday), so the difference comes from the test machine, not from this release; the cause is not determined yet. The package size is unchanged (zip 22.1 MiB).
- **Known limit:** in the native Markdown Preview, a very large document refreshes slowly after each edit (about 1.9 s for a 700 KB document); ordinary documents are not affected. Native tables have no border lines and a block quote has no left bar, unlike the browser drawing of 0.6.x.
- **Needs a manual check:** pointer and keyboard use with a real mouse, and a live screen reader session.
- **Not yet validated:** Windows 10, clean-machine installs, Linux/macOS (no Preview/Terminal host there yet).
