## MDLite 0.5.6 — lighter memory use and a Windows installer

A lightweight native editor (Qt 6 + Scintilla) with built-in Preview and Terminal. This release focuses on memory use and adds an installer.

### Highlights
- **Windows installer:** `MDLite-0.5.6-windows-x64-setup.exe` installs per user without administrator rights (an all-users install can be chosen), adds a Start menu shortcut and an optional desktop shortcut, warns if the WebView2 Runtime is missing, and can be removed from *Installed apps*. The portable zip is still available.
- **One shared browser runtime:** Preview and Terminal share one WebView2 environment. A closed Preview releases its browser after 30 s, and hidden surfaces use less memory. Folder + OpenAPI Preview + Terminal went from 285 to 203 MiB for the whole process tree.
- **Math and diagrams:** KaTeX formulas render in one background worker instead of one frame per formula (200 formulas: 409 s → 0.3 s, 591 → 201 MiB), and KaTeX fonts load correctly again. The Mermaid/PlantUML renderer is released after 60 s without use (6 diagrams: 170 → 105 MiB).
- **Opening large files:** opening a file no longer reserves 64 MiB up front or keeps extra copies of the text. Opening a 14 MiB binary file now peaks at 82 MiB instead of 312 MiB. Binary PDF/image Preview snapshots are built in one copy (63 → 14 MiB transient for a 14 MiB image).
- **Smaller package:** unused Qt network/TLS modules, image formats and styles were removed.
- **Fixes:** minimizing no longer blanks a binary Preview; Preview links are validated before opening; Terminal start failures can be retried; Quick Open no longer shows stale results; the window trims its memory after 30 s minimized.
- License: GPL-3.0-or-later, with the third-party licence set included in the package.

### Requirements
- Windows 10/11 x64. Preview and Terminal use the Microsoft Edge **WebView2 Runtime** (preinstalled on Windows 11).

### Install
- **Installer:** run `MDLite-0.5.6-windows-x64-setup.exe`. The app is not code-signed yet, so Windows SmartScreen may ask you to confirm ("More info" → "Run anyway").
- **Portable:** unzip `MDLite-0.5.6-windows-x64.zip` anywhere and run `Workspace.exe`.

Settings are stored in your user profile (AppData) and are kept when you uninstall or update.

### Validation and known limits
- Built with Qt 6.8.3 / MSVC 2022 on Windows 11. 36/36 automated tests passed. Deployment smoke tests passed for the package and for an installer install, and the silent uninstall removed the files and shortcut.
- Not yet validated: Windows 10, clean-machine installs, Linux/macOS (no Preview/Terminal host there yet), live screen-reader sessions.
- With Preview open on a large image, memory still peaks briefly inside WebView2 while it receives the image (≈215 MiB for a 14 MiB image).
- Editor-only memory is about 15 MiB at 1600×1000 px with no file open (more on large or high-DPI windows); the 30 MB target holds only for small windows.

Details: `docs/footprint-0.5.6.md` in the source archive. Third-party notices are included in the package (`licenses/`, `terminal/THIRD_PARTY_NOTICES.md`).
