## MDLite 0.8.0 — a much better Terminal, Run, Preview scroll sync and Notepad++-style tools

A lightweight native editor (Qt 6 + Scintilla) with built-in Preview and Terminal.

This release is mostly about the Terminal and about everyday editing tools. It was checked with a 208-case black-box acceptance run of the 0.8.0 build: no data-loss finding and no regression against 0.7.3 (details at the end).

### Changes since 0.7.3

**Terminal**
- **Tabs and profiles.** Up to ten tabs in one panel. A new tab starts the profile you pick: PowerShell, Command Prompt, Git Bash, your WSL distributions, Visual Studio developer prompts, or your own in `profiles.json` (Terminal › Open Terminal Profiles). ``Ctrl+Shift+` `` opens a tab, `Ctrl+Shift+W` closes one (MDLite asks first when a command is running), and `Ctrl+Tab` / `Ctrl+PgDn` switch tabs while the Terminal has focus.
- **Click paths and links.** `Ctrl+click` on a file path in the output opens the file in the editor, at the line and column when the output names them (`src\main.cpp:42:7`). `Ctrl+click` on a web address asks before it opens your browser.
- **Run.** *Run Active File* (`F5`), *Run Selection* (`F9`) and *Open in Terminal* (`Ctrl+Alt+T`) send the file, the selection or the folder to the Terminal; the command depends on the file type and the shell.
- **Programs behave as in other terminals.** Output is no longer dropped when a program prints very fast (a 100 MiB burst arrives complete), full-screen programs such as vim and Pi get the keys they ask for (Shift+Enter, Ctrl+Space, key releases, through Windows' "full key events" mode), copy and paste follow Windows Terminal, and the terminal engine (xterm.js) is now version 6. Settings gained font, size, line height, cursor, scrollback, and whether window shortcuts reach the shell.
- **Smarter surroundings.** A dot on a background tab and a taskbar flash when a program rings the bell; progress shown on the tab and on the taskbar button; a question before a multi-line paste into a shell that cannot tell pasted text from typing; files dropped on the Terminal are typed as paths; a program may copy text to your clipboard (it can never read it). An optional setting (off by default) marks each PowerShell command with a bar showing whether it succeeded, and `Ctrl+Up` / `Ctrl+Down` jump between commands.

**Preview**
- **The Preview follows the editor.** Scroll the editor and the Markdown Preview (native or browser) scrolls with it. Turn it off in Settings › Preview.
- Tables in the native Markdown Preview have border lines and alternating rows again (they were missing since 0.7.0).

**Editing tools (Notepad++-style)**
- **Lines:** sort (ascending, descending, ignoring case, by number, by length), reverse, join (`Ctrl+J`), remove duplicate, empty or blank lines, trim leading and trailing whitespace; **Title, Sentence and Invert case**.
- **Bookmarks:** `Ctrl+F2` toggles a bookmark in the gutter, `F2` and `Shift+F2` jump to the next and previous one.
- **Find in selection** (`Alt+L` in the Find bar) limits the match count, Find Next and Replace All to the selected text.
- **Optional auto-closing brackets and quotes** (Settings › Editor › Typing, off by default).
- **Encodings and line endings:** *Reopen with Encoding* and *Save with Encoding* (Windows code pages, Shift-JIS, GBK, Big5, EUC-KR and more; a file is only kept in the new reading if it writes back to the same bytes), and *Convert Line Endings* to LF, CRLF or CR, from the status bar or the Command Palette.
- **View helpers:** whitespace and line-ending marks, vertical rulers (Settings › Editor › Rulers), fold-level commands, and the indentation (tabs or spaces, width) is recognised when a file opens.
- **Markdown:** Enter continues lists, quotes and task items; *Toggle Task Item*, *Format Table*, *Promote Heading* and *Demote Heading* in Edit › Markdown.

**Documentation**
- The README, privacy statement and screenshots were updated for this version.

### Known issues
- After **Replace All, Undo or a case transform over many thousands of places** (for example 10,000 matches in a 1 MiB file, or 9,000 selections), the window can stay busy for several seconds (about 18 s in the test) **while a screen reader or another UI Automation client is running**; the edit itself is done in milliseconds. This was measured with such a client attached; it was not re-measured by hand without one for this release. Everyday edits are not affected.
- With a screen reader, menu shortcuts are announced as access keys (a limit of Qt's accessibility bridge).
- Not yet validated: Windows 10, clean-machine installs, a live screen-reader session and real-mouse use. Linux and macOS have no Preview or Terminal yet.

### Requirements
- Windows 10 (1809 or later) or Windows 11, x64.
- Documents that still need the browser (Markdown with diagrams or math, HTML, SVG, OpenAPI, YAML) and the Terminal use the Microsoft Edge **WebView2 Runtime**, which comes preinstalled on Windows 11.

### Install
- **Microsoft Store:** https://apps.microsoft.com/detail/9NGXBT327D13. It is signed by Microsoft, so there is no SmartScreen warning. The 0.8.0 update reaches the Store after certification.
- **Installer:** run `MDLite-0.8.0-windows-x64-setup.exe`. It updates an existing 0.5.x, 0.6.x or 0.7.x install in place. The app is not code-signed yet, so Windows SmartScreen may ask you to confirm: choose "More info", then "Run anyway".
- **Portable:** unzip `MDLite-0.8.0-windows-x64.zip` anywhere and run `MDLite.exe`. The portable copy does not register "Open with". If you unzip over an older portable copy, delete the old `preview` and `terminal` folders first.

Settings, `keybindings.json`, `profiles.json` and hot-exit backups are stored in your user profile (AppData). They are kept when you uninstall or update.

### Validation and known limits
- **Automated tests:** built with Qt 6.8.3 / MSVC 2022 on Windows 11. 114 automated tests, run one at a time: all 114 passed, none skipped.
- **Black-box checks:** an independent run of 208 acceptance cases against the 0.8.0 build: 160 passed, 28 passed with a documented change of method, 9 could not be run through the test channel, 3 are manual, 8 failed (the bulk-edit delay above, the screen-reader shortcut wording, and the expected result of one test that was wrong, not the product). No case that passed on 0.7.3 failed. The build tested has the same `MDLite.exe` as the one published here; only documentation and screenshots changed afterwards.
- **Install tests:** the deployment smoke test passed for the package and for the installed copy after a silent update from the published 0.7.3 installer (the update left exactly the package's 101 files and registered the 18 file types); the silent uninstall removed every file and the file-type registration.
- **Memory:** editor-only private working set was 17.2-17.4 MiB at a 1600×1000 px window (Explorer open, no file). A larger window costs more (Windows keeps a picture of every pixel); at 3200×2000 px it was 35.5-35.8 MiB. The zip is 22.4 MiB (0.7.3: 22.1 MiB).
- **Needs a manual check:** pointer and keyboard use with a real mouse, bulk edits without a screen reader attached, and a live screen reader session.
