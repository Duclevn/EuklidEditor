## MDLite 0.6.3 — Sublime Text look

A lightweight native editor (Qt 6 + Scintilla) with built-in Preview and Terminal.

### Changes since 0.6.2
- **Editor font.** The editor now uses Consolas, the font Sublime Text uses on Windows, at 14 px with tighter line spacing. On the same 1200×800 window it shows 39 lines instead of 33. Only fixed-width fonts can be chosen in Settings. If you never changed the size, it moves from the old default of 13 px to 14 px. A size you chose yourself is kept.
- **Compact gutter.** The empty symbol column next to the line numbers is gone, and the line numbers sit closer to the text. Fold arrows are thin chevrons. They appear when the mouse is over the gutter, but a folded block always shows its arrow.
- **Default theme: Mariana.** The Default theme now uses Sublime Text's Mariana colors (blue-grey editor, orange accent) with a light Explorer panel and activity bar. Dark and Light keep their colors and get the new font and gutter.
- **Fixed:** an automated Terminal test could count an unrelated process as a second shell. The app itself was not affected.

### Requirements
- Windows 10 (1809 or later) or Windows 11, x64.
- Preview and Terminal use the Microsoft Edge **WebView2 Runtime**, which comes preinstalled on Windows 11.

### Install
- **Microsoft Store:** https://apps.microsoft.com/detail/9NGXBT327D13. It is signed by Microsoft, so there is no SmartScreen warning. The 0.6.3 update reaches the Store after certification.
- **Installer:** run `MDLite-0.6.3-windows-x64-setup.exe`. It updates an existing 0.5.x or 0.6.x install in place. The app is not code-signed yet, so Windows SmartScreen may ask you to confirm: choose "More info", then "Run anyway".
- **Portable:** unzip `MDLite-0.6.3-windows-x64.zip` anywhere and run `MDLite.exe`. The portable copy does not register "Open with". If you unzip over an older portable copy, delete the old `preview` and `terminal` folders first.

Settings, `keybindings.json` and hot-exit backups are stored in your user profile (AppData). They are kept when you uninstall or update.

### Validation and known limits
- **Automated tests:** built with Qt 6.8.3 / MSVC 2022 on Windows 11. All 54 automated tests passed, run one at a time. New checks cover:
  - the fixed-width font, line height and gutter widths;
  - fold arrows that appear only while the mouse is over the gutter;
  - moving the old 13 px default to 14 px;
  - contrast for the Default theme and its light Explorer.
- **Install tests:**
  - Deployment smoke tests passed for the package and for an installer update from 0.6.2. The update left exactly the package's files and registered the file types.
  - The silent uninstall removed every file and the file-type registration.
- **Memory:** editor-only memory is about 15.1 MiB private working set (1600×1000 window, one run), against 15.6 MiB for 0.6.2. Preview and Terminal memory was not measured again; this release did not change them.
- **Known issues:**
  - Programs started from the Microsoft Store version of PowerShell run outside MDLite's process group.
  - "Open with" in the Microsoft Store version has not yet been checked on a Store install.
- **Not yet validated:** Windows 10, clean-machine installs, Linux/macOS (no Preview/Terminal host there yet), live screen-reader sessions.

Third-party notices are included in the package (`licenses/`, `terminal/THIRD_PARTY_NOTICES.md`).

### Source code
The complete source code of this version is attached as `MDLite-0.6.3-source.zip`. The *Source code (zip)* and *(tar.gz)* links that GitHub adds to every release contain only the public files of this repository (README, privacy statement, license, release notes).

Building it: follow `docs/BUILDING.md` in the archive. In this version a first build in a new build directory stops while copying the console host; create the folder `build/cmake/Release/conpty` and build again.
