## MDLite 0.5.11 — Default theme with a light Preview, clearer focus, smoother resizing

A lightweight native editor (Qt 6 + Scintilla) with built-in Preview and Terminal.

### Changes since 0.5.10
- **New "Default" theme.** The workspace and editor use the Dark theme, and the Preview page is always light, so documents look the way they print or appear on the web. New installs start with Default. If you already picked Dark or Light, that choice is kept. Switch themes with *Color Theme…* (Ctrl+K, Ctrl+T) or in Settings.
- **You can see which pane you are working in.** Only the Editor, Preview or Terminal you last used carries the accent mark: the active tab's top edge, or a highlighted PREVIEW/TERMINAL title.
- **No focus ring after a click.** Title-bar and side-bar buttons show a focus ring only when you reach them with Tab.
- **Smoother resizing.** Dragging the dividers next to Preview and Terminal is faster: about 7 ms per step instead of 12 ms for Editor/Preview, and about 10 ms instead of 14 ms for Editor/Terminal. The Terminal now resizes only when its size changes by a whole character cell.
- **Microsoft Store packaging.** MDLite has been submitted to the Microsoft Store. Store installs are signed by Microsoft and show no SmartScreen warning. The GitHub downloads below are unchanged and still unsigned.

### Requirements
- Windows 10 (1809 or later) or Windows 11, x64. Preview and Terminal use the Microsoft Edge **WebView2 Runtime** (preinstalled on Windows 11).

### Install
- **Installer:** run `MDLite-0.5.11-windows-x64-setup.exe`. It updates an existing 0.5.x install in place. The app is not code-signed yet, so Windows SmartScreen may ask you to confirm ("More info" → "Run anyway").
- **Portable:** unzip `MDLite-0.5.11-windows-x64.zip` anywhere and run `MDLite.exe`. If you unzip over an older portable copy, delete the old `preview` and `terminal` folders first.

Settings and hot-exit backups are stored in your user profile (AppData) and are kept when you uninstall or update.

### Validation and known limits
- Built with Qt 6.8.3 / MSVC 2022 on Windows 11. All 42 automated tests passed, run one at a time. New checks cover the Default theme (Dark editor and Preview header, Light Preview page and colors).
- Deployment smoke tests passed for the package and for an installer update from 0.5.10. The update left no old files behind, and the silent uninstall removed every file. The Store package was started from an unpacked test layout with its package identity.
- Known issues: in the Terminal, Ctrl+C does not stop a console program such as `ping` under PowerShell (it works under Command Prompt). Programs started from the Microsoft Store version of PowerShell run outside MDLite's process group.
- Not yet validated: Windows 10, clean-machine installs, Linux/macOS (no Preview/Terminal host there yet), live screen-reader sessions.

Third-party notices are included in the package (`licenses/`, `terminal/THIRD_PARTY_NOTICES.md`).
