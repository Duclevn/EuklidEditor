## MDLite 0.5.5 — Monokai-inspired UI/UX redesign

A lightweight native editor (Qt 6 + Scintilla) with built-in Preview and Terminal. This release is a complete visual and interaction redesign.

### Highlights
- **Warm Monokai Pro–inspired Dark theme** (no harsh black) and a matching warm **Light** theme; every color pair passes WCAG contrast checks.
- **Clean structure:** two surfaces and a single 1 px hairline between panes; aligned 34 px pane headers; no more double borders.
- **Custom title bar on Windows** with menus, a search-style command center, layout toggles and native-feeling caption buttons (Aero Snap and Windows 11 Snap Layouts still work). Set `WORKSPACE_NATIVE_FRAME=1` to use the system caption instead.
- **Command Palette** as a floating popup: fuzzy search with highlighted matches and shortcut keycaps, **Quick Open** (`Ctrl+P`), **Go to Line** (`Ctrl+G`), and quick picks for theme, language and indentation.
- **Floating Find/Replace** with inline Aa / ab / .* toggles, `n of m` counter, highlight-all and find-as-you-type.
- **Editor:** smart highlight of the selected word, brace matching, scrollbars only when needed, Word Wrap (`Alt+Z`), Zoom (`Ctrl+=` / `Ctrl+-` / `Ctrl+0`).
- **Tabs:** file-type icons, modified dot, middle-click close, drag to reorder, context menu.
- **Explorer:** colored file-type icons, single-click open, header actions, first-run "Open Folder" state, drag & drop of files and folders onto the window.
- **Preview/Terminal:** no white flash in Dark; Terminal can be maximized or hidden from its header.
- Clickable status bar (Go to Line, indentation, language), grouped Settings, app icon, Alt-key menu mnemonics.

### Requirements
- Windows 10/11 x64 with the Microsoft Edge **WebView2 Runtime** (preinstalled on Windows 11) for Preview and Terminal.

### Install
Unzip `MDLite-0.5.5-windows-x64.zip` anywhere and run `Workspace.exe`. No installer is required.

### Validation and known limits
- Built with Qt 6.8.3 / MSVC 2022; 29/29 automated tests and a deployment smoke test passed on Windows 11 (4K, 200 % scaling).
- Not yet validated: Windows 10, Linux/macOS (no Preview/Terminal host there yet), live screen-reader sessions, clean-machine installs.
- Editor-only memory is about 58–60 MiB working set on the test machine; the 30 MB target is still open.
