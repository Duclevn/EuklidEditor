## MDLite 0.6.1 — View only mode and "Open with"

A lightweight native editor (Qt 6 + Scintilla) with built-in Preview and Terminal.

### Changes since 0.6.0
- **View only mode.** Click the mode button in the title bar (or press `Ctrl+Alt+V`) and MDLite becomes a calm, preview-only reader: no Explorer, tabs or Terminal, just the document.
  - Markdown, JSON, CSV, OpenAPI, diagrams, PDF and images open in the Preview.
  - Code and other text open as read-only text.
  - Files with no viewer show a short notice instead of raw bytes.
  - `Ctrl` `+` / `Ctrl` `-` zoom the page.
  - MDLite remembers the mode. Files you open by double-click or "Open with" then go straight to the Preview. Click **Edit** to go back; your tabs and unsaved work are kept.
- **"Open with".** The installer and the Microsoft Store version now register MDLite for 82 file types: Markdown, JSON, YAML, TOML, CSV, XML, logs, and the common programming and script languages. You can choose MDLite in "Open with" or make it the default app for a type.
- **One window.** Opening files while MDLite is running adds them to that window instead of starting a second one, including several files selected together. Use `MDLite.exe --new-window` to get a separate window.
- **Fixed:** in the Terminal, `Ctrl+C` did not stop a console program such as `ping` under PowerShell.

### Requirements
- Windows 10 (1809 or later) or Windows 11, x64.
- Preview and Terminal use the Microsoft Edge **WebView2 Runtime**, which comes preinstalled on Windows 11.

### Install
- **Microsoft Store:** https://apps.microsoft.com/detail/9NGXBT327D13 (signed by Microsoft, no SmartScreen warning; the 0.6.1 update reaches the Store after certification).
- **Installer:** run `MDLite-0.6.1-windows-x64-setup.exe`. It updates an existing 0.5.x or 0.6.0 install in place. The app is not code-signed yet, so Windows SmartScreen may ask you to confirm: choose "More info", then "Run anyway".
- **Portable:** unzip `MDLite-0.6.1-windows-x64.zip` anywhere and run `MDLite.exe`. The portable copy does not register "Open with". If you unzip over an older portable copy, delete the old `preview` and `terminal` folders first.

Settings, `keybindings.json` and hot-exit backups are stored in your user profile (AppData). They are kept when you uninstall or update.

### Validation and known limits
- **Automated tests:** built with Qt 6.8.3 / MSVC 2022 on Windows 11. All 52 automated tests passed, run one at a time. New tests cover:
  - View only: the switch and its key, the layout, each kind of file, hot exit and the remembered mode;
  - opening files with spaces and Unicode names, and handing them to the running window;
  - the file-type registration in the Store manifest and the installer script;
  - `Ctrl+C` typed into the Terminal under PowerShell and Command Prompt.
- **Install tests:** deployment smoke tests passed for the package and for an installer update from 0.6.0, which left exactly the package's files and registered the file types. The silent uninstall removed every file and the file-type registration.
- **Memory:** editor-only memory is unchanged at about 15.6 MiB private working set (1600×1000 window). A Markdown file in View only uses about the same memory as Edit mode with the Preview open (about 97 MiB for the whole process tree, WebView2 included).
- **Known issues:**
  - Programs started from the Microsoft Store version of PowerShell run outside MDLite's process group.
  - "Open with" in the Microsoft Store version has not yet been checked on a Store install; it is checked once this update is certified.
- **Not yet validated:** Windows 10, clean-machine installs, Linux/macOS (no Preview/Terminal host there yet), live screen-reader sessions.

Third-party notices are included in the package (`licenses/`, `terminal/THIRD_PARTY_NOTICES.md`).
