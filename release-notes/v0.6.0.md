## MDLite 0.6.0 — VS Code / Sublime Text keyboard shortcuts

A lightweight native editor (Qt 6 + Scintilla) with built-in Preview and Terminal.

### Changes since 0.5.11
- **Multiple cursors, the VS Code / Sublime way.**
  - `Ctrl+D` adds the next occurrence of the word or selection.
  - `Ctrl+Shift+L` (or `Alt+F3`) selects every occurrence.
  - `Ctrl+Alt+Up/Down` adds a cursor above or below.
  - `Shift+Alt+I` puts a cursor at the end of each selected line.
  - `Ctrl+U` removes the last cursor added.
  - Typing and paste go to every cursor.
- **Line commands.** All of these work on every selection and undo in one step:
  - Move line: `Alt+Up/Down`
  - Copy line: `Shift+Alt+Up/Down`, `Ctrl+Shift+D`
  - Delete line: `Ctrl+Shift+K`
  - Insert line below / above: `Ctrl+Enter` / `Ctrl+Shift+Enter`
  - Select line: `Ctrl+L`
  - Toggle comment: `Ctrl+/`
  - Indent / outdent: `Ctrl+]` / `Ctrl+[`
  - Go to bracket: `Ctrl+Shift+\`
  - Upper / lower case: `Ctrl+K Ctrl+U` / `Ctrl+K Ctrl+L`
  - Column (box) selection is now `Ctrl+Shift+Alt+Arrows` (or `Alt`+drag).
- **Go to Symbol** (`Ctrl+Shift+O`, or type `@` in Go to File) lists the headings, classes and functions of the current file. It covers Markdown, C/C++, C#, Java, Rust, PHP, Go, Kotlin, Swift, JavaScript/TypeScript, Python, shell, PowerShell, CSS, JSON, YAML and INI/TOML, with no language server.
- **Go to File** (`Ctrl+P`) accepts `name:12` or `name:12:5` to open a file at a line and column.
- **Jump back and forward** with `Alt+Left` / `Alt+Right` or the mouse back/forward buttons.
- **Focus keys:** `Ctrl+1` focuses the editor and `Ctrl+Shift+E` the Explorer.
- **Window keys from Terminal and Preview.** While the Terminal or Preview has focus, the Command Palette, Go to File, the panel toggles, the focus keys and editor switching still work. Shell keys such as `Ctrl+C` stay in the Terminal.
- **Your own shortcuts.** *File > Keyboard Shortcuts (JSON)* opens `keybindings.json` in the VS Code format, with every command and its default keys listed as comments. Saving the file applies it at once, for example:
  - `{ "key": "ctrl+alt+o", "command": "edit.goToSymbol" }` adds a key.
  - `{ "key": "ctrl+d", "command": "-edit.addSelectionToNextFindMatch" }` removes one.
- **Fixed:** after typing in the Terminal, clicking the editor did not bring the keyboard back, so typing kept going to the Terminal.

### Requirements
- Windows 10 (1809 or later) or Windows 11, x64.
- Preview and Terminal use the Microsoft Edge **WebView2 Runtime**, which comes preinstalled on Windows 11.

### Install
- **Installer:** run `MDLite-0.6.0-windows-x64-setup.exe`. It updates an existing 0.5.x install in place. The app is not code-signed yet, so Windows SmartScreen may ask you to confirm: choose "More info", then "Run anyway".
- **Portable:** unzip `MDLite-0.6.0-windows-x64.zip` anywhere and run `MDLite.exe`. If you unzip over an older portable copy, delete the old `preview` and `terminal` folders first.

Settings, `keybindings.json` and hot-exit backups are stored in your user profile (AppData). They are kept when you uninstall or update.

### Validation and known limits
- **Automated tests:** built with Qt 6.8.3 / MSVC 2022 on Windows 11. All 47 automated tests passed, run one at a time. New tests cover:
  - the line commands, multi-cursor and jump list;
  - the symbol outline for every listed language;
  - `keybindings.json` parsing and merging;
  - key presses through the window shortcuts;
  - the Terminal→editor focus fix, with native click messages.
- **Install tests:** deployment smoke tests passed for the package and for an installer update from 0.5.11, which left exactly the package's files. The silent uninstall removed every file.
- **Memory:** editor-only memory is unchanged at about 15.5 MiB private working set (1600×1000 window).
- **Known issues:**
  - In the Terminal, Ctrl+C does not stop a console program such as `ping` under PowerShell. It works under Command Prompt.
  - Programs started from the Microsoft Store version of PowerShell run outside MDLite's process group.
- **Not yet validated:** Windows 10, clean-machine installs, Linux/macOS (no Preview/Terminal host there yet), live screen-reader sessions.

Third-party notices are included in the package (`licenses/`, `terminal/THIRD_PARTY_NOTICES.md`).
