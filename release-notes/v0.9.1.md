## Euklid Editor 0.9.1 — a home for your coding agent, Export as PDF and HTML with its own CSS

A lightweight native editor (Qt 6 + Scintilla) with built-in Preview and Terminal.

### Changes since 0.9.0

**The Terminal as a home for your AI coding agent** (Euklid Editor ships no AI of its own: your agent, your account)
- The Terminal can sit as a **full-height column** on the right of the editor and Preview (`Terminal: Toggle Placement`), and **Terminal: Toggle Maximized** (`Ctrl+Shift+M`) fills the window. Both choices are remembered. The top-level menu is now **Run** (Run Active File, Run Selection, the Terminal items).
- **Claude Code link.** Claude Code started in the Terminal connects to Euklid Editor by itself: it sees your selection and opens files, and the changes it proposes appear in the Compare window, where you **Accept** or **Reject** them. The link listens on 127.0.0.1 only, is protected by a token, and ends with the last Terminal shell. It is on by default and can be switched off in Settings (`Terminal > Claude Code`).
- **Agent profiles.** Claude Code, Codex, opencode, Copilot CLI, Gemini CLI and Pi appear in the Terminal's New Tab menu when they are installed.
- **Shift+Enter** starts a new line in agent prompts instead of sending the message.
- **Insert File Reference** types `path:10-20` for the current selection into the Terminal, for agents that have no link.

**Documents**
- **Export as PDF** for Markdown (File menu, or the button in the Preview header): plain Markdown is written by the native engine, documents with diagrams or formulas by the browser engine.
- **HTML files keep their own CSS** in the Preview. Scripts, remote fonts and network requests stay blocked.
- **Tools > Compare with Version Before Reload** shows what a file looked like before it changed on disk and was reloaded.
- **Run Active File** runs PowerShell scripts from Command Prompt and Git Bash even when the machine's script policy is Restricted (this process only, only for the file you chose to run).

**Fixes and polish**
- Replace All, Undo and multi-cursor edits no longer freeze the window while a screen reader or another UI Automation client is running (10,000 replacements: about 20 s before, about 0.1 s now).
- Stop on the last Terminal shell now also ends the Claude Code link.
- CSV Preview columns no longer cut their values; Settings fits short screens (sections scroll, Save and Cancel stay in view).
- Reset Zoom returns to the default 14 px editor font.
- The User Guide text is readable in every theme and follows a theme change; the Help menu shows the real shortcut for Show All Commands; the Claude Code review window shows the full path of the file.
- A possible crash or hang in the Markdown Preview when the theme changes is fixed.
- Explorer polish (inset, chevron alignment, selection outline only after keyboard use) and file dialogs that open in a sensible folder.

### Known issues
- Opening a file whose single line is about 10 MB takes about 6 seconds.
- After **Reset Zoom** the line spacing can be 2 px tighter than at a fresh start, until you restart.
- HTML Preview does not load local `<link rel="stylesheet">` files, CSS `url()` pictures or inline `<svg>`.
- With a screen reader, menu shortcuts are announced as access keys (a limit of Qt's accessibility bridge).
- Not yet validated: Windows 10, clean-machine installs, a live screen-reader session and real-mouse use. Linux and macOS have no Preview or Terminal yet.

### Requirements
- Windows 10 (1809 or later) or Windows 11, x64.
- Documents that still need the browser (Markdown with diagrams or math, HTML, SVG, OpenAPI, YAML) and the Terminal use the Microsoft Edge **WebView2 Runtime**, which comes preinstalled on Windows 11.

### Install
- **Microsoft Store:** https://apps.microsoft.com/detail/9NGXBT327D13. It is signed by Microsoft, so there is no SmartScreen warning. The 0.9.1 update reaches the Store after certification.
- **Installer:** run `EuklidEditor-0.9.1-windows-x64-setup.exe`. It updates an existing install in place (settings, keybindings, profiles, hot-exit tabs and the browser profile are kept). The app is not code-signed yet, so Windows SmartScreen may ask you to confirm: choose "More info", then "Run anyway".
- **Portable:** unzip `EuklidEditor-0.9.1-windows-x64.zip` anywhere and run `EuklidEditor.exe`. The portable copy does not register "Open with". If you unzip over an older portable copy, delete the old `preview` and `terminal` folders first.

Settings, `keybindings.json`, `profiles.json` and hot-exit backups are stored in your user profile (AppData). They are kept when you uninstall or update.

### Validation and known limits
- **Automated tests:** built with Qt 6.8.3 / MSVC 2022 on Windows 11. 130 automated tests, run one at a time: all 130 passed, none skipped. The `EuklidEditor.exe` these tests ran on is the one published here (SHA-256 in the table above).
- **Scripted checks:** the 34-case scripted acceptance set passed on the packaged build. A separate, independent run of about 250 checks on the release candidate found no risk to user data; the issues it found were fixed (the list above) or are listed under Known issues.
- **Install tests:** three silent installs of the published installer: an update of the released 0.9.0 installer into a temporary folder, the same update with the default folder, and a fresh install. Each left exactly the package's 101 files, 18 file types and 82 "Open with" values, and each silent uninstall removed every file and registration. The machine's own registry entries and shortcuts were unchanged afterwards.
- **Memory:** editor-only private working set was 17.5 MiB at a 1600×1000 px window (Explorer open, no file); the 0.9.0 build measured the same way the same day gave 17.3-17.5 MiB. A larger window costs more (Windows keeps a picture of every pixel). The zip is 22.5 MiB (0.9.0: 22.4).
- **Needs a manual check:** pointer and keyboard use with a real mouse, Settings on a 1366×768 screen, and a live screen reader session.
