## Euklid Editor 1.0.1 — Vietnamese typing with Unikey fixed

A lightweight native editor (Qt 6 + Scintilla) with built-in Preview and Terminal.

### Changes since 1.0.0

**Fixes**
- Vietnamese typing with Unikey (VNI and Telex) works on every machine again. On some computers each changed letter was lost ("Vie6t5 Nam" gave "Viet Nam") because the new letter arrived before the Backspace that should have removed the old one. The editor now keeps the order the input method sends.

### Known limits
- A Markdown file with a very large number of headings can make the native Preview slow.
- A Markdown file over 20,000 lines shows its first 2,000 lines in the Preview, with a notice.
- HTML Preview does not load local `<link rel="stylesheet">` files, CSS `url()` pictures or inline `<svg>`.
- With a screen reader, menu shortcuts are announced as access keys (a limit of Qt's accessibility bridge).
- Not yet validated: Windows 10, clean-machine installs, a live screen-reader session and real-mouse use. Windows is the only supported platform; Linux and macOS builds are unsupported nightlies.

### Requirements
- Windows 10 (1809 or later) or Windows 11, x64.
- Documents that still need the browser (Markdown with diagrams or math, HTML, SVG, OpenAPI, YAML) and the Terminal use the Microsoft Edge **WebView2 Runtime**, which comes preinstalled on Windows 11.

### Install
- **Microsoft Store:** https://apps.microsoft.com/detail/9NGXBT327D13. It is signed by Microsoft, so there is no SmartScreen warning. The 1.0.1 update reaches the Store after certification.
- **Installer:** run `EuklidEditor-1.0.1-windows-x64-setup.exe`. It updates an existing install in place (settings, keybindings, profiles, hot-exit tabs and the browser profile are kept). The app is not code-signed yet, so Windows SmartScreen may ask you to confirm: choose "More info", then "Run anyway".
- **Portable:** unzip `EuklidEditor-1.0.1-windows-x64.zip` anywhere and run `EuklidEditor.exe`. The portable copy does not register "Open with" or the document icon. If you unzip over an older portable copy, delete the old `preview` and `terminal` folders first.

Settings, `keybindings.json`, `profiles.json` and hot-exit backups are stored in your user profile (AppData). They are kept when you uninstall or update.

### Validation
- **Automated tests:** built with Qt 6.12.0 / MSVC 2022 on Windows 11. 141 automated tests, run one at a time: all 141 passed, none skipped. The `EuklidEditor.exe` these tests ran on is the one published here (SHA-256 in the table above).
- **Install tests:** three silent installs of the published installer: an update of the released 1.0.0 installer into a temporary folder, the same update with the default folder, and a fresh install. Each left exactly the package's 102 files, 18 file types pointing at the document icon and 82 "Open with" values, and each silent uninstall removed every file and registration.
- **Vietnamese input:** checked with the real Unikey 4.6 (VNI) on the computer where 1.0.0 lost the letters.
